# Update Project State

## Purpose
Update the project state file after completing significant work.

## When to Update
- After completing a feature or task
- After fixing bugs
- After creating new files
- Before starting a new significant task

## How to Update

Edit `.kilocode/rules/memory-bank/context.md` with:

```markdown
## Last Updated: YYYY-MM-DD

### Changes Made
- Describe what was completed
- List files created or modified
- Note any issues fixed

### Current Status
- What's working
- What's pending
- Any blockers

### Next Steps
- What needs to be done next
```

## Quick Update Format

```markdown
### DATE - Task Name
**Status**: Complete/In Progress/Blocked
**Actions**: 
1. Action taken
2. Another action

**Files**:
- `path/to/file.py` - description
```

## Important
- Always update the date
- Be specific about file changes
- Include any new issues discovered
